# UrlShortener

A Java Spring Boot application for creating short links from URLs of any length. Registered users can track detailed statistics and use links with UTM tags.

**👉 Live Demo:**  https://short-link1.ru/main

---

## Features

- **Shorten any URL:** Create a compact short link with a generated code or a custom string in the path
- Short link has expiration period

### For Registered Users
- **Detailed Statistics:** View your short link's performance
  - Total clicks and unique clicks
  - Charts showing daily & hourly traffic
  - Device, browser, and operating system charts
  - Geographic data (countries and cities of your visitors)
- **UTM Tagging:**
  - UTM Generator, support for Source, Medium, Campaign and optional Content
  - View a UTM statistics table for clicks on each UTM variation
- Extend expiration period

---

## Tech Stack

- **Backend:** Java, Spring Boot, Spring MVC, Spring Data, Spring Security, PostgreSQL, JPA, REST API, Gradle, JUnit
- **Frontend:** JavaScript, HTML, CSS (AI-generated and edited by me)
